# Avisos de terceros

Los archivos de dependencies/ se copian sin modificar desde los paquetes instalados por `npm run licenses`. inventory.json registra sus versiones y SPDX. Los avisos son aplicables a los componentes correspondientes; no conceden derechos sobre la franquicia One Piece ni establecen una licencia pública para el código nuevo de este repositorio.

Phaser y EventEmitter3 son dependencias de ejecución. Vite, TypeScript, esbuild, Playwright y sus dependencias son herramientas de desarrollo/compilación/pruebas. Los comentarios legales de los bundles se conservan durante la compilación.
